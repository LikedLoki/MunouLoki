# MunouLoki
数十分で作られた人工無能です。

## 使い方 / Usage
### JA
1. ReleasesからMunouLoki.zipをダウンロード
2. 解凍
3. main.exeを実行
4. うんたらかんたら
### EN
1. Download MunouLoki.zip from the “Releases”
2. Extract the files
3. Run main.exe
4. Blah, blah, blah
## その他 / etc...
### JA
- main.exe実行時に警告が出る場合があります。基本的には大丈夫なんですが、実行が恐ろしいと思う人はリポジトリからmain.goをダウンロードして、GoLangコンパイラーで変換してから実行しても良い。
- memoryFileはただの文字列が書かれたファイルなので、いくらでも改ざんできる。
### EN
- A warning may appear when you run main.exe. It’s generally fine, but if you’re worried about running it, you can download main.go, compile it with the GoLang compiler, and run it that way.
- memoryFile is just a file containing a string, so it can be tampered with however you like.
